# StockWise

Aplicação web para cadastro e acompanhamento de produtos e estoque, feita com React, Vite e Tailwind CSS.

## Executar localmente

Requisitos: Node.js e npm.

```bash
npm install
npm run dev
```

Abra no navegador o endereço que o Vite mostrar no terminal.

## Funcionalidades

- Dashboard com contagens e valor estimado do estoque.
- Cadastro, edição e exclusão de produtos.
- Busca por nome e categoria.
- Classificação automática de estoque normal, baixo e sem estoque.
- Ajuste de quantidades na página de estoque.
- Resumo por categoria e exportação de relatório CSV.
- Configuração do limite de estoque baixo.
- Armazenamento local dos produtos e configurações no navegador.

Os dados ficam no armazenamento local do navegador e não são sincronizados entre dispositivos ou usuários.
