# StockWise

Aplicação web para cadastro e acompanhamento de produtos e estoque. O StockWise ajuda a visualizar quantidades, identificar itens com estoque baixo e consultar o valor estimado dos produtos cadastrados.

## Funcionalidades

- Dashboard com resumo do estoque.
- Cadastro, edição e exclusão de produtos.
- Busca por nome e categoria.
- Ajuste rápido de quantidades.
- Indicadores de estoque normal, baixo ou zerado.
- Resumo de produtos por categoria.
- Exportação de relatórios em CSV.
- Configuração do limite de estoque baixo.

## Tecnologias

- React
- Vite
- Tailwind CSS
- React Router
- Chart.js
